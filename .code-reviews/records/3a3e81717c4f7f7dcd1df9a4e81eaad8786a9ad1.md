## Summary

Stack: React (Vite, TypeScript, React Router, Redux Toolkit, Tailwind, MSW).

Adds the D2 todo filters. A new `TodoFilters` component renders All / Active / Completed as
links inside a labelled `<nav>`. Each link shows a count from `selectTodoCounts`, and the
current filter gets `aria-current`. The choice is stored in `?status=` through the new
`searchForFilter` helper, which keeps other query params and removes `status` for All.
`TodosPage` renders the filters above `TodoList`. The list gets an accessible name, and the
new strings are in `messages`. The new tests cover counts, the current marker, the EC-54
fallback, URL updates, Back navigation and keeping other params. The page test checks
filtering from start to finish.

Re-review: both earlier findings are fixed. Count badges now render only when
`status === "success"`, and a test covers the idle, loading and error states. A new
`useTodoFilter` hook holds the URL parsing, and both `TodoFilters` and `useFilteredTodos`
use it. The related test files pass (81 tests) and `tsc -b` is clean.
