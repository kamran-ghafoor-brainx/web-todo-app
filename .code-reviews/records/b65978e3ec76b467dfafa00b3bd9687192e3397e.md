## Summary

Stack: React (Vite + TypeScript, MSW mock backend). Scope: all changes (everything staged).

This change bumps the mock database schema to version 2 by adding a `todos` table (`MockTodo`). It seeds five demo todos for the demo account. The due dates are date-only strings relative to today and cover overdue, due today, completed and no-due-date cases. A saved version 1 copy in localStorage is now upgraded in place, so its users and sessions are kept, instead of being thrown away. The version check is split into `hasAuthTables`, `isDbState` and `isDbStateV1`. New tests cover the upgrade path, the seed contents, date maths across month boundaries and the newest-first ordering.

Checked: `tsc -b` is clean, eslint on `src/mocks` and `tests/mocks` is clean, and `vitest run tests/mocks` passes (44/44). `db.ts` imports values from `seed.ts`, and `seed.ts` imports only types from `db.ts`, so there is no runtime circular import. No correctness or security problems were found. There are two Low findings.
