## Summary

Stack: React (React 19, TypeScript, zod 4). Adds the todo form schema (`todoFormSchema`) built from the existing `titleField`/`descriptionField`/`dueDateField`, with an optional due date that accepts `""` for an empty date input. Also adds `emptyTodoFormValues` and two converters: `toTodoFormValues` (API todo → form, null → "") and `toTodoRequest` (form → API body, "" → null). The return type `Required<CreateTodoRequest>` can also be assigned to `UpdateTodoRequest`, so clearing a field on edit correctly sends `null`. Tests cover EC-40/EC-41 limits, trimming, emoji/RTL text, leap-year and invalid dates, and a round trip. I ran the suite (19/19 pass) and `tsc --noEmit` (clean).

Note: `toTodoRequest` does not trim. It expects values that `todoFormSchema` has already parsed, as `zodResolver`/`handleSubmit` provides. The type system doesn't enforce this, but no caller passes raw values today, so I didn't raise it as a finding.
